Dice Atrium

Dice est une famille d'applications gratuites et open source que j'écris pour ma propre table de jeu et que je partage avec d'autres maîtres de jeu. Chacune fait une seule chose : DiceAudio s'occupe du son d'une séance, DiceCombats des combats, et d'autres suivront. Aucune ne demande d'installateur ni de compte, et vos données restent sur votre machine.

DiceAudio

Musiques, ambiances et effets sonores pour une séance

Rassemblez vos musiques, ambiances et effets sonores dans une seule bibliothèque, construisez des scènes qui suivent ce qui se passe à la table, et pilotez toute la soirée depuis une seule fenêtre. De tout ce qui est présenté ici, c'est l'application dont je suis le plus fier. Les outils audio que j'ai essayés avant de l'écrire pêchaient tous quelque part : un bon catalogue auquel on ne peut pas ajouter ses propres fichiers, un lecteur médiocre, un abonnement, ou une interface qui demande une soirée d'apprentissage. DiceAudio travaille avec vos propres fichiers, a un vrai lecteur, et se pilote simplement en direct. Il sert aussi très bien en dehors du jeu de rôle, de l'escape game au théâtre amateur.

  • Bibliothèque étiquetée, avec un téléchargeur pour YouTube, SoundCloud et bien d'autres sites
  • Scènes en couches, avec des contextes comme calme ou bagarre qui fondent de l'un à l'autre
  • Scénarios : la liste ordonnée de ce que vous comptez jouer, regroupée par aventure
  • API HTTP locale, désactivée par défaut, pour qu'un autre programme pilote la lecture

DiceCombats

Gestionnaire de combats pour n'importe quel système

Construisez vos créatures avec les champs dont votre système a besoin, suivez l'initiative et les points de vie pendant le combat, et laissez l'application s'occuper du reste : types de dégâts et résistances, journal de combat, et automatisations qui appellent d'autres programmes quand quelque chose se passe.

  • Fiches de créatures personnalisées avec dix types de champs, réutilisables d'une créature à l'autre
  • Bestiaire et groupes de joueurs, avec import depuis aidedd.org pour D&D
  • Calcul des dégâts affiché en détail avant validation
  • Journal de combat avec statistiques par créature, exportable en JSON

Relier les applications

Les applications ne sont pas intégrées entre elles d'origine. Ce qu'elles partagent, c'est un langage commun : DiceCombats peut envoyer des requêtes HTTP quand quelque chose se passe dans un combat, et DiceAudio peut les recevoir sur un serveur local que vous activez dans ses réglages. Relier les deux est une configuration manuelle, requête par requête.

En pratique, je m'en sers surtout pour piloter des choses extérieures à la famille Dice : un jingle quand un joueur réussit un coup critique, un éclairage qui change quand un combat commence, ou le déclenchement d'un outil privé. Tout ce qui accepte une requête HTTP convient, une ampoule connectée aussi bien qu'un overlay de stream. Une intégration plus poussée entre les applications viendra peut-être plus tard. Mes propres séances n'en ont pas encore besoin, mais les briques sont là si vous voulez les assembler vous-même.

À propos de l'IA

J'ai écrit les applications Dice entièrement moi-même jusqu'au début 2026. Depuis, j'utilise Claude Code pour implémenter plus vite les nouvelles fonctionnalités, ce qui me laisse plus de temps pour mes scénarios de JDR. L'IA est ici un outil de développement : les fonctionnalités, les choix de conception et la direction de chaque application viennent toujours de moi, un maître de jeu qui construit des outils pour d'autres maîtres de jeu.
